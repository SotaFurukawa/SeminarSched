# はじめて使う人のための簡単操作ガイド

対象: SummerCourseScheduler `1.4.2 (Beta)`

この文書は、初めて時間割を作る担当者が、作業の順番を迷わないための簡易版です。
各画面の詳しい説明は[利用者マニュアル](user_manual.md)、問題が起きた場合は
[トラブルシューティング](troubleshooting.md)を参照してください。

## 1. このアプリでできること

生徒の受講可能日時、講師の出勤可能日時、担当できる科目、集団授業などを照合し、
個別授業の時間割を自動作成します。自動作成後は手動で調整し、Excel、PDF、CSVへ
出力できます。

次の条件は、都合が悪くても破って配置しません。

- 生徒または講師が「不可」と回答した日時
- 講師が指導できない科目
- 同じ生徒または講師の時間重複
- 講師1人に同時に3人以上
- 1対1必須の授業への別生徒の追加
- 優先度5で指定された通常担当講師以外への配置
- 生徒の連続上限や、許可されていない空きコマ
- 集団授業、固定授業、休校日との重複

条件を満たせない授業は、無理に配置せず「未配置」として理由を表示します。

## 2. 最初に準備するもの

- Windows 10または11（x64）のPC
- 講習期間、開校日、各コマの時刻
- 生徒一覧（IDはアプリが自動採番）
- 講師一覧（IDはアプリが自動採番）
- 科目、必要授業回数、通常担当講師
- 講師ごとの指導可能科目
- 生徒と講師のアンケート回答
- 集団授業がある場合は、その日付、時刻、担当講師、受講生

IDを事前に用意する必要はありません。氏名を登録すると、生徒は`S-0001`、講師は
`T-0001`から未使用の番号をアプリが順番に割り当てます。同姓同名の区別や内部参照に
使うため、採番後のIDはアプリが保持します。

## 3. 全体の作業順

次の順番で進めます。

1. ①設定：プロジェクトを作り、開校日、コマ、科目、共通基本情報を確認する
2. ②アンケート作成：設定日時を反映した生徒用・講師用フォーム作成キットを出力する
3. ③アンケート取込み：回答を検証し、受講希望と参加／出勤不可日時を反映する
4. ④事前確定：保護者等と調整済みの生徒・講師・日付・コマを必要な分だけ固定する
5. ⑤時間割：集団授業と入力エラーを確認し、自動作成後に必要な手動調整を行う
6. ⑥出力：未配置と警告を確認し、ExcelまたはPDFへ出力してバックアップを作る

前の作業にエラーが残っていると、後の自動作成を開始できないことがあります。

## 4. 起動する

### インストーラー版

Startメニューから「夏期講習時間割作成アプリ」を開きます。

### ポータブル版

ZIPを右クリックして「すべて展開」し、展開先の
`SummerCourseScheduler.exe`を開きます。ZIPの中から直接起動しないでください。

未署名のリリース候補では、Windows SmartScreenの警告が出る場合があります。
公式GitHub ReleaseのURLとSHA-256を確認し、組織の規則で実行できない場合は
PC管理者へ相談してください。SmartScreenやウイルス対策を無効にしないでください。

## 5. プロジェクトを作る

1. 左側の「ホーム」を開きます。
2. 「新規プロジェクト」を選びます。
3. 2020～2070年の年度と春期／夏期／冬期を選び、開始日、終了日を年・月・日の
   プルダウンで選択します。
4. `2026夏期講習`のようなプロジェクト名が自動表示されることを確認します。
5. 「作成」を押します。保存先はアプリが自動管理します。

保存される`.jukuschedule`には氏名や時間割が含まれます。共有範囲が不明な場所や
公開フォルダーへ保存しないでください。作業中はPC内のローカルフォルダーを推奨します。

## 6. 開校日、コマ、科目を確認する

左側の「設定」を開き、次を順番に確認します。

### 開校日

- 授業を行う日を「開校」にします。
- 休校日は「休校」にします。
- アンケートを取る前に日程を確定します。

### コマ

初期設定は次のとおりです。

| コマ | 時刻 |
|---|---|
| Y | 14:10～15:30 |
| Z | 15:40～17:00 |
| A | 17:10～18:30 |
| B | 18:40～20:00 |
| C | 20:10～21:30 |

校舎の時刻と違う場合は、アンケート作成前に修正してください。

### 科目

使う科目が登録されているか確認します。小学校の中学受験科目とそれ以外、高校数学IA・
数学IIBC・数学IIIは別科目です。

## 7. 生徒・講師・受講希望を登録する

少人数なら「生徒」「講師」画面から登録できます。人数が多い場合はホームの
「新規で基本情報を作成」でExcelを作り、編集後に「作成した基本情報を反映」を使います。
通常は、ホーム上部の大きな青い「反映済みの基本情報を開いて編集」を使います。

生徒・講師の基本情報ではIDを入力しません。在籍はA列のセル内チェックボックスで切り替え、
姓を入力するとチェック、ID候補、既定値が自動表示されます。行に在籍・退籍の文字は
入力しません。薄い黄色のセルは入力必須です。保存後にアプリへ
反映するとIDが正式採番されます。講師対応科目や通常授業では、隣の「名前から選択」で氏名を選ぶと
IDが自動的に関連付けられます。科目も名前から選択できます。同姓同名の場合だけは、
採番後に表示されるIDを確認して選択してください。

### 生徒

- 生徒ID（自動採番）
- 氏名
- 学年
- 最大連続コマ数（通常は2）
- 空きコマを許可するか

Excelの学年は、小学校を`S1`～`S6`、中学校を`J1`～`J3`、高校を`H1`～`H3`で
入力します（例: 高2は`H2`）。既存の日本語表記のExcelも引き続き取り込めます。

最大連続コマ数、空きコマ許可、在籍の既定値は、それぞれ`2`、`なし`、チェックありです。
チェックを外した入力済み行は灰色になります。セル内チェックボックスにはMicrosoft 365
またはExcel 2024以降が必要で、古いExcelでは`TRUE`／`FALSE`として表示されます。

### 生徒ごとの受講希望

- 科目
- 必要回数
- 通常担当講師
- 通常担当の優先度1～5
- 第1～第3希望講師
- 1対1必須

優先度5は「その通常担当講師でなければ未配置にする」という絶対条件です。
単なる「強い希望」として設定しないでください。

### 講師

- 講師ID（自動採番）
- 氏名
- 空きコマを許可するか
- 指導できる科目

講師の指導可能科目は、アンケートではなく塾側で登録します。

## 8. アンケートを取り込む

Googleフォームの作り方は
[Googleフォーム アンケート作成・取込みガイド](google_forms_questionnaire_guide.md)
を参照してください。

Googleフォームを新しく作る場合は、先に①で開校日とコマを確定します。次に②で
「アンケート作成」を開き、フォーム名、回答締切、問い合わせ先を選択・入力して
「フォーム作成キットを保存」を選びます。出力フォルダー内の手順書に従い、3つの
`.gs`ファイルを別々のGoogle Apps Scriptプロジェクトへ貼り付けて実行してください。
開校日、有効なコマ、科目はアプリから自動的に反映されます。Apps Scriptのデプロイは
不要です。初めての場合は「赤い案内つき手順を見る」で、貼り付け、初回権限確認、
URL確認、回答CSVの保存までの9段階をアプリ内で確認できます。

3つ目は講師の指導可能科目用です。講師のメールアドレスを収集せず、小・中・高の26科目を
複数選択できます。回答は確認後、ホームの共通基本情報xlsxへ反映してください。

回答が集まったら、回答スプレッドシートで「ファイル」→「ダウンロード」→
「カンマ区切り形式（.csv）」を選びます。Z・A・B・Cなど複数のチェックが1セルに
入っていても正常なので、そのまま保存します。

1. ③「アンケート取込み」で生徒回答CSVを選びます。
2. 講師回答CSVを選びます。
3. 「2ファイルを検証」を押します。
4. エラーと警告を確認し、必要なら基本情報または回答を修正して選び直します。
5. エラーが0件になったら「検証済み内容を反映」を選びます。

基本情報にない在籍生・講師は赤で表示されます。体験生は画面で「体験生として登録」を
選択でき、プロジェクト内だけへ登録できます。反映した回答原本は`.jukuschedule`内へ
保存されるため、元のダウンロードファイルを移動しても失われません。

## 9. 集団授業を取り込む

集団授業がなければ、この手順は省略できます。

1. 「集団授業」を開きます。
2. テンプレートを出力します。
3. 「集団授業」シートへ日付、開始・終了時刻、担当講師等を入力します。
4. 「受講者」シートへ集団授業IDと生徒IDを入力します。
5. 取り込んで検証し、エラーがなければ反映します。

集団授業と時間が重なる担当講師・受講生は、個別授業へ配置されません。

## 10. 入力エラーを確認する

「未配置・警告」を開き、入力検証を実行します。

- エラー: 修正しないと自動作成できません。
- 警告: 内容を確認します。自動作成できる場合もあります。
- 情報: 現在の状態を知らせる表示です。

エラー文にID、行番号、列名が出た場合は、元データを修正して再取込みします。

## 11. 時間割を自動作成する

1. 「時間割」を開きます。
2. 入力エラーが0件であることを確認します。
3. 初回は「標準（120秒）」を選びます。
4. 「自動作成を実行」を選びます。
5. 終了後、配置済み数、未配置数、警告を確認します。

`FEASIBLE`は、絶対条件を守った時間割が作れたことを意味します。
`OPTIMAL`でなくても、実用可能な結果の場合があります。

処理中に中止した結果は、現在の時間割を置き換えません。PCを強制終了せず、
安全な中止が完了するまで待ってください。

## 12. 未配置・手動編集・ロック

未配置がある場合は、その理由を確認します。「不可」を「可能」へ勝手に変えたり、
優先度5を無断で解除したりしないでください。

時間割カードを移動すると、移動先が次の色で表示されます。

- 緑: 移動可能
- 黄: 移動可能だが、希望条件等が悪化
- 赤: 絶対条件違反のため移動不可

残したい授業はロックします。再最適化すると、ロックした授業を保持して残りを
作り直します。

## 13. Excel・PDFへ出力する

1. 「出力」を開きます。
2. 「最新データを再読込み」を選びます。
3. 帳票とExcelまたはPDFを選びます。
4. PDFは印刷プレビューを確認します。
5. 保存先を選び、出力します。

出力ファイルと印刷物には個人情報があります。不要になったファイルや印刷物は、
組織の規則に従って安全に削除・廃棄してください。

## 14. 終了前にバックアップする

1. 「ホーム」を開きます。
2. バックアップまたは手動保存を選びます。
3. 元の`.jukuschedule`とは別の安全な場所へ保存します。
4. バックアップが作成されたことを確認してから終了します。

接続中の`.jukuschedule`をエクスプローラーでコピーするのではなく、アプリの
バックアップ機能を使用してください。

## 15. 最低限の最終確認

- [ ] 年度、講習区分、自動設定されたプロジェクト名、期間が正しい
- [ ] 開校日と休校日が正しい
- [ ] 自動採番された生徒・講師IDを手作業で変更していない
- [ ] 必要授業回数が正しい
- [ ] 優先度5と1対1必須を担当者が確認した
- [ ] 生徒・講師アンケートの全回答を反映した
- [ ] 集団授業を反映した
- [ ] 入力エラーが0件
- [ ] 未配置と警告を担当者が確認した
- [ ] 手動調整後の時間割を再確認した
- [ ] ExcelまたはPDFを目視確認した
- [ ] バックアップを作成した
- [ ] 出力ファイルの共有先と印刷物の管理方法を確認した
