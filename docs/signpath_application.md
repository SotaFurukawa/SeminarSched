# SignPath Foundation申請記録（終了）

Status: **申請は不承認となり、この手順は使用しません。**

SignPath Foundationから、GitHub上の利用実績、外部記事、第三者による言及、組織的支援
などの公開信頼指標が現時点では不足しているとの通知を受けました。技術的な不具合や
ソフトウェア品質を理由とする不承認ではありません。

プロジェクト所有者は、社内利用向け成果物を未署名で配布する方針を選択しました。

- SignPathのOrganization、Project、Signing Policyを作成しません。
- `SIGNPATH_API_TOKEN`等のSecretや変数をGitHubへ登録しません。
- SignPath GitHub Appをインストールしません。
- 署名要求や手動承認をリリース手順へ追加しません。
- 成果物を署名済みと表示しません。

現在の配布・完全性確認方法は[未署名配布・完全性確認方針](code_signing_policy.md)を参照
してください。再申請または別の署名方式を採用する場合、この終了済み手順をそのまま
再利用せず、新しいADR、脅威評価、証明書・秘密情報の管理設計、CIテストを用意します。
