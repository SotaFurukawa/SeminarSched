# ADR 0006: Phase 3取込みの検証境界・差分・監査

- Status: Accepted
- Date: 2026-07-29

## Context

Phase 3では、生徒・講師の日時希望をxlsxまたはCSVから、集団授業を2シートのxlsxから
取り込む。入力元は利用者が編集できるため、ファイルを読み取れたことだけではDBへ
反映してよいとは判断できない。また、削除候補、優先度5、1対1契約、通常担当講師、
講師資格、休校日、任意時刻の集団授業衝突を安全に扱う必要がある。

最上位仕様の `StudentAvailability` は生徒・日付・コマ単位であり科目を持たない。
一方、生徒アンケートには科目コードと希望講師が含まれる。

## Decision

### 層と処理段階

取込みを次の段階へ分ける。

1. `infrastructure.importing` がxlsx/CSVを読み、文字コード、シート、元ヘッダー、
   元セル、未知列を保持する。
2. schemaと列マッピングがcanonical fieldへの変換、必須値、日付、時刻、0/1/2、
   行キー重複を検査する。
3. Application Serviceが現在のプロジェクトDBと照合し、ID、名前、科目、受講希望、
   講師資格、講習期間、開校日、集団授業衝突を検査する。
4. 既存DBとの差分を追加、変更、変更なし、削除候補に分類する。
5. 利用者が確認した後、Application Serviceが入力ファイルを再読込み・再検証し、
   業務データ、`ImportBatch`、`AuditLog`を1トランザクションで保存する。

QMLはこのApplication ServiceをViewModel経由で呼び、DB、ファイル解析、検証を直接
実行しない。

### 削除と保護項目

- 入力に存在しない既存行は削除候補として表示するだけにする。
- 削除は利用者が明示的に選択した場合だけ同じトランザクションで反映する。
- 通常担当講師、優先度5、1対1契約に相当する未知列へ値がある入力はエラーとして
  拒否する。
- 生徒アンケートから更新できるLessonRequest項目は第1～第3希望講師だけとする。
- `StudentAvailability` へ科目列を追加しない。科目コードはLessonRequestと希望講師
  資格の照合に使う。
- 同じ生徒・科目について複数日の希望講師が矛盾する場合は、適用順で結果が変わらない
  ようエラーにする。

### マッピングと監査

- 手動列マッピングは最新の同種 `ImportBatch.mapping_json` へプロジェクト単位で
  保存し、次回の候補として再利用する。
- `source_file_name` にはbasenameだけを保存し、端末のディレクトリ構成を監査情報へ
  持ち込まない。
- `AuditLog` は取込み操作と件数を追記する。エラーを握り潰さず、監査行の保存に
  失敗した場合も業務データをロールバックする。

### 時刻区間

集団授業と将来の個別授業候補は半開区間 `[start, end)` として比較する。終了時刻と
次の開始時刻が等しいだけなら重複ではない。集団授業はY/Z/A/B/Cとの完全一致を要求
しない。

### ValidationIssue

ファイル固有の行・列エラーは取込みプレビューに保持する。保存済みプロジェクト全体の
検証は別サービスで再計算し、前回の未解決 `ValidationIssue` を解決済みにした後、
現在のエラー・警告・情報を追加する。エラーが1件でもあれば将来の最適化開始を許可
しない。

## 必須の取込み安全要件と実装上の選択

ここでいう必須要件は、入力をDBへ安全に反映するための受入条件であり、マスター仕様
17章の時間割最適化における「ハード制約」とは区別する。

必須の取込み安全要件:

- 0/1/2以外を保存しない。
- 優先度5、通常担当講師、1対1契約をアンケートから変更しない。
- 未登録ID、期間外、休校日、資格違反、集団授業の講師・生徒重複を反映しない。
- エラーを含むプレビューを反映しない。
- 削除候補を自動削除しない。
- 反映と監査を1トランザクションにする。
- 集団授業の区間境界が接するだけの場合は重複にしない。

実装上の選択:

- マッピングの保存先として専用設定表を増やさず、最新ImportBatchを再利用する。
- 新しいアンケート取込みで指定された資格のない希望講師は行エラーとして反映を
  拒否する。既にDBに存在する資格のない希望講師はプロジェクト全体検証で警告とし、
  Phase 4の候補講師にはしない。通常担当や固定集団授業の資格違反はエラーとする。
- 同姓同名と無効化済みマスター参照は警告として表示する。

## Consequences

- プレビュー後にファイルやDBが変わっても、適用直前の再検証で古い判断を使わない。
- 未知列を保持するため、保護項目を見落としにくく、手動マッピングにも対応できる。
- セル数に比例する差分を表示でき、削除の影響を利用者が確認できる。
- Phase 4は検証済みavailability、集団授業、ValidationIssueをDBから読み取れる。
- 専用MappingProfile表が必要になるほど要件が拡大した場合は、後続migrationで
  ImportBatchから分離する。
