# Googleフォーム自動作成ツール

このディレクトリには、SummerCourseScheduler向けのGoogleフォームと回答先
Google Sheetsを作成するGoogle Apps Scriptがあります。

ここにあるファイルは、開発・確認用の固定例です。通常の講習では、アプリの①で開校日と
コマを設定した後、②「アンケート取込み」→「Googleフォームを作る」から作成キットを
出力してください。現在の開校日、有効なコマ、有効な科目が生徒用・講師用スクリプトへ
自動的に反映され、同じフォルダーに操作手順も作成されます。

- `create_student_questionnaire.gs`: 生徒・保護者用
- `create_teacher_questionnaire.gs`: 講師用

## 実行方法

1. [Google Apps Script](https://script.google.com/)を開き、「新しいプロジェクト」を選ぶ。
2. 生徒用または講師用のスクリプトを選び、`Code.gs`へ内容を貼り付ける。
3. ファイル冒頭の設定でタイトル、締切、問い合わせ先、開校日、コマ等を実際の
   講習に合わせる。
4. 生徒用は`createStudentQuestionnaire`、講師用は`createTeacherQuestionnaire`を
   選び、「実行」を押す。
5. 初回のみ、フォームとスプレッドシートを作成する権限を許可する。
6. 実行ログに表示される3つのURLを開き、質問と共有設定を確認する。

生徒用フォームでは、学年の回答に応じて回答先のセクションを自動で切り替えます。
小1～小6には小学校、中1～中3には中学校、高1～高3には高校の科目だけが表示されます。
講師が分岐を手作業で設定する必要はありません。

## 講師が毎年作成する場合の最短手順

1. `QUESTIONNAIRE_CONFIG`のタイトル、締切、問い合わせ先、開校日、時間帯だけを変更する。
2. `createStudentQuestionnaire`を選択して実行する。
3. 初回のGoogle権限確認を許可する。
4. 実行ログの「フォーム編集URL」で内容を確認する。
5. 「回答用URL」を保護者へ案内し、「回答原本URL」は担当講師だけで共有する。

Google Apps Scriptの「デプロイ」は不要です。別年度のフォームを作るときは、Apps Script
プロジェクト自体をコピーして設定を変更すると、既存フォームを壊さずに運用できます。

生徒用で作成される質問は、メールアドレス、個人情報の利用目的確認、姓、名、学年、在籍区分、
最大4科目の受講教科と回数、受講不可日時、確認、特記事項、夏期学力テストです。
時間割作成に不要な住所、学校名、電話番号は収集しません。

講師用ではメールアドレスを収集しません。作成される質問は、個人情報の利用目的確認、姓、名、
出勤不可日時、確認、勤務に関する特記事項です。講師の指導可能科目や空きコマ許可は
塾側のマスター情報なので、フォーム回答では変更しません。

同じApps Scriptプロジェクトで再実行しても、作成済みフォームがある場合は新しい
フォームを重複作成しません。URLを再表示するときは`showCreatedQuestionnaireUrls`を
実行してください。

質問構成を変更した後に新しいフォームへ置き換える場合は、
`createReplacementStudentQuestionnaire`を1回だけ実行してください。旧フォームと旧回答表は
削除されず、新しいフォームと回答表が別に作られます。その後は通常どおり重複作成を防止します。

## 個人情報の扱い

スクリプトは実行したGoogleアカウント内にフォームと回答表を作成します。回答を
外部サービスやSummerCourseSchedulerへ自動送信しません。回答表は一般公開せず、
閲覧者を業務上必要な担当者だけに限定してください。実回答をGitHubへ追加しないで
ください。
