# Phase 6 Windows実機手動確認

## 1. 目的と記録方法

この手順は、自動テストだけでは保証できないWindows実機のQt PDF表示、DPI、
表計算ソフト／PDF viewerとの互換性、ファイルロック、保存dialogを確認する。
実行日、Windows版、表示倍率、PySide6版、Excelまたは互換ソフト、PDF viewer、
プリンター名、各項目の結果とスクリーンショット保存先を社内の安全な記録へ残す。

スクリーンショットと生成物には氏名等が含まれ得る。Git、GitHub issue、CI artifact、
一般チャット、外部クラウドへ添付しない。このリポジトリへ結果のxlsx、PDF、CSV、
`.jukuschedule`、ログを追加しない。

## 2. 前提

- Windows 10または11 x64、Python 3.12系の開発環境を使用する。
- `python -m summer_scheduler`で起動し、migration head
  `20260729_0006`まで適用できている。
- 実在人物を含まない匿名プロジェクトを用意する。
- プロジェクトには複数日、休校日、Y / Z / A / B / C、複数講師、長い日本語の架空名、
  1対2、1対1必須、集団授業、ロック、手動変更、未配置、未対応警告を含める。
- Phase 4 / 5の独立検証を通る時間割を保存する。ハード制約違反を作って試験を
  続行しない。
- 保存先として、例えば
  `C:\Users\<利用者>\Documents\夏期講習テスト\架空校`のような日本語パスを用意する。
- ロゴ確認には個人情報を含まない5MB以下のPNGまたはJPEGを用意する。

業務上の参考PDFは個人情報を含む可能性があるため、公開リポジトリやテストfixtureへ
含めない。この試験でも開かず、特定資料との見た目比較は対象外として記録する。

## 3. 起動と出力画面

1. PowerShellから`python -m summer_scheduler`を実行する。
2. 匿名プロジェクトを開き、サイドバーの「出力」を選ぶ。
3. 帳票件数、集団授業数、未配置数、警告数がプロジェクトの現在値と一致することを
   確認する。
4. 最小ウィンドウ幅と通常最大化の両方で、保存先、設定、対象選択、プレビューが
   操作できることを確認する。
5. Windowsの表示倍率100%と150%で、文字やボタンが重なったり画面外へ到達不能に
   なったりしないことを確認する。
6. 「最新状態を再読込み」で件数と選択肢が更新され、エラー時は日本語メッセージが
   表示されることを確認する。

## 4. PDF印刷プレビュー

1. 帳票を「全体時間割」、形式をPDFにする。
2. 用紙A3、横、1ページ当たり日数1、講師列数を少なめに設定し、複数ページになる
   対象を選ぶ。
3. 「印刷プレビューを更新」を押す。
4. 生成中もウィンドウが応答し、完了後にページ数が1以上で表示されることを確認する。
5. 前／次ボタンで先頭から末尾まで移動し、表示中ページと総ページ数が正しいことを
   確認する。
6. 倍率sliderを50%、100%、200%、300%へ動かし、拡大縮小とscrollが機能することを
   確認する。
7. 「幅に合わせる」「全体表示」が機能し、ページ移動後も描画が崩れないことを
   確認する。
8. 校舎名、講習名、更新日時、日付、コマ、開始・終了時刻、講師、生徒、学年、科目、
   凡例、ページ番号が読め、日本語が文字化けしないことを確認する。
9. 1対1、集団、ロック、警告、手動変更、未確定、休校が、色だけでなく文字マーカーでも
   判別できることを確認する。
10. 長い架空氏名が隣のセルへはみ出さず、行列の対応がずれないことを確認する。
11. 日数または講師列を過密にし、読める縮尺に収まらない場合は、極小文字のPDFではなく
    設定を減らすよう日本語エラーになることを確認する。
12. 「閉じる」でプレビューを消せることを確認する。アプリ終了後、
    `%TEMP%`配下に今回の`summer_scheduler_preview_`一時PDFが残らないことを確認する。

## 5. 全体時間割Excel

1. 帳票を「全体時間割」、形式をExcelにし、日本語フォルダーへ
   `夏期講習時間割.xlsx`として生成する。
2. Excelまたは使用予定の互換ソフトで開き、警告なしにブックを読めることを確認する。
3. 日付と講師数に応じたシート／ページ分割、日付ブロック、Y / Z / A / B / C、
   開始・終了時刻、講師列、最大2名分の表示、集団授業、休校が正しいことを確認する。
4. 罫線、セル結合、折返し、縮小表示、列幅、凡例、更新日時を確認する。
5. 印刷プレビューで用紙、向き、印刷範囲、改ページ、繰り返し文書見出し、
   ヘッダー／フッター、ページ番号が正しいことを確認する。
6. A3対応プリンターまたはMicrosoft Print to PDFを選び、ドライバー上でも
   A3横とページ境界が保持されることを確認する。実際に紙へ印刷する必要はない。
7. 長い架空氏名、先頭が`=` / `+` / `-` / `@`の架空文字列が数式として実行されず、
   表示用文字列として扱われることを確認する。

Excel出力には現時点でロゴ画像を埋め込まない。ロゴの手動確認はPDFで行い、
Excelにロゴがないことを不具合と誤認しない。ただし、将来Excelにも必要と判断した場合は
Phase 6の残課題として別途合意する。

## 6. 全体時間割PDFとロゴ

1. 匿名のPNGまたはJPEGロゴを選び、出力設定を保存する。用紙等の帳票設定は
   プロジェクト単位、ロゴパスは校舎単位で保存されることを区別して記録する。
2. 全体時間割PDFのプレビューを更新し、ヘッダーのロゴ、校舎名、講習名、更新日時が
   読めることを確認する。
3. 日本語フォルダーへ`夏期講習時間割.pdf`として保存する。
4. Edgeまたは業務で使用するPDF viewerで開き、全ページの日本語、背景色、罫線、
   ページ寸法、向き、ページ番号を確認する。
5. viewerの印刷プレビューでA3横、余白、改ページを確認する。
6. 5MBを超える画像、存在しない画像、未対応拡張子を指定した場合、外部通信や
   部分PDF生成ではなく日本語エラーになることを確認する。
7. ロゴを解除して設定保存し、再起動後のプレビューにロゴが出ないことを確認する。

ロゴパスは`Campus.logo_path_optional`を正本とする校舎マスターのローカルパスであり、
プロジェクト別の`output_settings`へは重複保存しない。ロゴファイル自体も
プロジェクトDBへ埋め込まれないため、別PCへ移動した場合はそのPC上の安全なファイルを
再指定する。

## 7. 生徒別、講師別、未配置・警告

### 生徒別

1. ExcelとPDFの両方を生成する。
2. 1人1ページで、生徒名、学年、講習名、日付、コマ、時刻、科目、講師、1対1／1対2、
   備考、未配置残数を確認する。
3. 「複数人をまとめる」に変更し、ページ数とページ内の生徒が切り替わることを確認する。
4. 生徒選択を一部だけにし、選択外の生徒が出力されないことを確認する。

### 講師別

1. ExcelとPDFの両方を生成する。
2. 講師名、日付、コマ、時刻、生徒1／2、学年・科目、集団授業、連続勤務範囲、
   合計稼働コマ数を確認する。
3. 講師と日付を一部だけ選択し、選択外の講師／日付が出力されないことを確認する。

### 未配置・警告

1. ExcelとPDFの両方を生成する。
2. 未配置一覧に、生徒、科目、必要、配置済、不足、主な理由、解決候補、優先度、
   通常担当、1対1、備考があることを確認する。
3. 「単独配置可」と表示された候補は、現在の他Assignmentを変えず対象1sessionだけを
   追加して独立validatorを通った候補であることを確認する。複数候補を同時に適用可能、
   または最適解という意味に読み替えない。
4. 単独配置可能な候補がない行では、診断コードに対応した条件確認案が表示されることを
   確認する。
5. 警告一覧にseverity、issue type、日付、コマ、生徒、講師、内容、対応状況があり、
   現在の全体検証結果と一致することを確認する。

## 8. 割当て生データCSV

1. 帳票を「割当て生データ」に切り替え、形式がCSVになることを確認する。
2. BOMを有効にし、日本語パスへ生成する。Excelで開いて日本語が文字化けしないことを
   確認する。
3. 次の18列が順番どおりであることを確認する。

```text
project,campus,date,slot,start_time,end_time,teacher_id,teacher_name,
student_id,student_name,grade,subject_code,subject_name,
one_to_one_required,is_locked,is_manual,group_lesson,note
```

4. 個別Assignmentと集団授業の行、boolean値、改行・commaを含む備考を確認する。
5. 日付、講師、生徒を一部だけ選択し、CSVにも同じfilterが適用されることを確認する。
6. BOMを無効にして別名生成し、ファイル先頭がUTF-8 BOMではないことを確認する。
7. 先頭が`=` / `+` / `-` / `@`の架空値が表計算ソフトで数式実行されないことを
   確認する。
8. CSVでは印刷プレビューが無効になり、その理由が表示されることを確認する。

## 9. 上書き、失敗、原子的保存

### 同名上書き

1. 任意の帳票を一度生成する。
2. 同じ保存先で再生成し、確認なしには置換されないことを確認する。
3. 上書き確認で「いいえ」を選び、既存ファイルのhashと内容が変わらないことを確認する。
4. 再度生成して「はい」を選び、正常生成後だけ既存ファイルが置き換わることを確認する。

### ファイルロック／権限エラー

専用の試験フォルダーだけを使う。Windowsや利用者profileのACLは変更しない。

1. 既存xlsxをExcelで開いたままにするか、次のPowerShellで専用試験ファイルを
   排他openする。

```powershell
$lockedPath = Join-Path $env:USERPROFILE "Documents\夏期講習テスト\ロック確認.xlsx"
$lockedStream = [System.IO.File]::Open(
    $lockedPath,
    [System.IO.FileMode]::OpenOrCreate,
    [System.IO.FileAccess]::ReadWrite,
    [System.IO.FileShare]::None
)
```

2. アプリで同じファイルを選び、上書きを承認する。
3. 権限または他アプリのロックを確認する日本語エラーになり、既存ファイルが先に
   削除されず、同じフォルダーに`.tmp`が残らないことを確認する。
4. 必ず次を実行してlockを解放する。

```powershell
$lockedStream.Dispose()
```

5. 同じ保存先へ再出力し、正常に完了することを確認する。

## 10. 設定保存と再読込み

用紙、向き、表示項目等はプロジェクト単位、ロゴだけは校舎単位である。次の手順では
両者を同じ「出力設定を保存」操作から保存しても、DB上の正本が異なることを確認する。

1. A4縦、日数1、講師列3、文字サイズ、余白、ファイル名規則
   `{project}_{report}_{date}`、生徒別まとめ、BOM無効へ変更する。
2. 表示項目を一部変更し、各状態の色と文字マーカーを有効な`#RRGGBB`と文字列へ変更する。
3. 日本語の保存先と匿名ロゴを選び、「出力設定を保存」を押す。
4. 出力画面を開き直し、アプリを再起動し、同じプロジェクトで帳票設定と校舎ロゴが
   復元されることを確認する。
5. 別プロジェクトではそのプロジェクトの保存設定またはYAML既定値が使われ、用紙等の
   設定が混ざらないことを確認する。ロゴはプロジェクト設定ではなく、そのプロジェクトが
   参照する校舎マスターの値になることを確認する。
6. 未保存の変更を行い「元に戻す」を押し、最後に保存した値へ戻ることを確認する。
7. `config.yaml`の`output`既定値は、まだプロジェクト設定を保存していない
   プロジェクトの帳票設定だけに適用され、校舎ロゴの正本にならないことを確認する。
8. 範囲外の数値、不正色、Windowsで使用不能なファイル名規則は保存されず、
   日本語エラーになることを確認する。

## 11. 個人情報とローカル性

1. 出力、プロジェクトDB、ロゴ、プレビューが指定PCのローカルパスだけに作られることを
   確認する。
2. 出力中に外部認証、ブラウザー、クラウドupload、telemetryが起動しないことを
   確認する。
3. 通常ログに帳票本文、氏名一覧、CSV行、ロゴ内容が書かれていないことを確認する。
4. `git status --short`で、xlsx、PDF、CSV、`.jukuschedule`、ログ、一時ファイルが
   Git管理対象へ追加されていないことを確認する。
5. 試験完了後、生成物、試験DB、スクリーンショット、ロゴを組織の保持規則に従って
   安全に削除または保管する。削除前に実データでないことと対象パスを再確認する。

## 12. 合否

次を満たした場合にWindows実機確認を合格とする。

- 日本語と長い架空名が読め、行列、ページ、対象filterが正しい。
- Excel、PDF、CSVの必須情報が欠落せず、モノクロでも文字マーカーで状態を判別できる。
- プレビューのページ送り、拡大縮小、幅合わせ、全体表示が動作する。
- 上書き、権限／lock、過密レイアウト、無効設定が明示エラーになり、既存ファイルを壊さない。
- 帳票設定がプロジェクト単位、ロゴが校舎単位で保存・再読込みされる。
- 外部通信がなく、個人情報をGitや外部サービスへ送っていない。

不合格項目は、再現手順、期待値、実際の結果、影響する帳票、Windows／Qt／viewer情報を
記録する。個人情報を含む生成物そのものは添付しない。
